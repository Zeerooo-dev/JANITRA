# One-time account code copy review

Mode: after (session override). Scope: the requested tap-to-copy action only. Existing navy/white JANITRA account screen and Roboto direction retained, ENERGY 1 / RHYTHM 2 / MOTION 1. The native copy glyph marks the clipboard action; a native text button provides keyboard/focus behavior and a minimum 48-pixel touch target. No new asset, dependency, navigation or backend change.

Findings: no additional UI changes proposed in the reviewed scope.

- Hard Gate PASS in automated scope: tapping the displayed code copies the exact code and shows success; a platform clipboard failure displays a retry message and keeps the code available; background/resume still hides the one-time code. Six Personnel account widget tests passed; Flutter analysis found no issues. The clipboard is only written on explicit user action, and feedback is suppressed if the code screen loses its code during the asynchronous write.
- Purpose Gate PASS: copy icon and tooltip explain the requested action; native control and feedback avoid redesigning the account screen.
- Liveliness PASS for existing direction: layout, type, structural spacing, primary Done action and native interaction remain consistent with the established screen.
- Craftsmanship PASS within reviewed scope: success and failure actions are connected to Flutter's clipboard API, with no code value in confirmation/error messages. Native button focus/keyboard behavior is retained by inspection. Physical clipboard sharing, large text and all desktop/mobile interactions were not manually exercised; no physical acceptance claim is made.

The OS clipboard intentionally retains the copied code for handoff after the account screen hides it. This change does not add automatic clipboard clearing or change the one-time code's expiry/replacement rules.
