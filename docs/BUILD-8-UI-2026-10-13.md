- Shared native styling: white headers/cards, pale canvas, navy actions, consistent fields/dialogs/bottom navigation, and registered bundled Roboto fonts.
- Login: supplied checkmark identity, centered welcome, white form card.
- Supervisor: Home / Tasks / Team / Reports. Header building button opens Workplaces; initials button opens Profile.
- Employee: Home / My Tasks / Profile, next-task card, status cards, grouped account controls.

- Personnel directory, scheduling lists, Profile and report chooser follow the same native card styling.
- Visited tabs retain state and scrolling. Agency changes get separately keyed task/team/report pages; authorization invalidation still disposes the workspace.

Existing MFA, offline work, history and export controls remain available. Real data and status take precedence over static sample content.
