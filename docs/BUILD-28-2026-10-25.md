# JANITRA Build 28 review and release

Version: **1.0.1+28**. Scope: inspect the supplied local UI updates, fix release blockers, and publish a new signed GitHub release. No backend deployment or data changes are needed.

## Updated behavior

Home guides authorized managers through agency, client and workplace setup. It reuses the existing protected forms and Team navigation. Admin retains the ability to create unassigned accounts before company setup; Site-Specific Supervisors cannot create agencies or client companies.

The workspace uses the supplied aurora background and glass surfaces for setup, overview, tasks, Team and Reports. Existing custom colors remain authoritative. High Contrast falls back to solid surfaces; app inactivity, system reduced motion, Motion Off and disabled TickerMode pause the background timer. The background paints independently of content and does not replace navigation state or intercept taps.

Task filtering, offline-storage information and empty states use the updated UI. Task Details and all protected task operations retain their existing behavior.
