# JANITRA 1.0.2

Android Build 29. October 27, 2026. The owner confirmed phone testing and approved this GitHub release. No Google Play publication is planned.

- Privacy Policy in Profile → Settings and on login, readable offline without authentication. Independent developer/operator: Zeerooo-dev. Personal email removed at the operator's request; existing workplace contact arrangements are described. Effective and last-updated dates: October 27, 2026.
- One policy source generates the bundled app content and public HTML. Includes corrected Company-Wide Supervisor access, Supabase hosting/Gmail/GitHub providers, PIN/MFA, encrypted offline drafts, report sharing, retained history and privacy-request disclosures.
- High Contrast setup cards now use readable text on their solid surfaces. Top and bottom bars use appearance-derived colors with contrast-checked labels and icons.
- About JANITRA includes Check for Updates, with the existing secure update dialog, Later, download/installer handling, no-update feedback and connection-error handling.

Production-signed APK, source ZIP, changes, Privacy Policy HTML, verification report and SHA-256 checksums are provided with the release. Existing production-signed installations can update without uninstalling; older development-signed installations still require the documented signing transition.

Validation: 241 Flutter tests, 9 native APK safety tests, policy-generation and release-tool checks passed locally. Flutter analysis has no errors or warnings; one existing informational style note remains. Phone acceptance was reported by the owner.

No backend, production-data or permission changes. Supabase diagnostic-log and backup entitlements were verified read-only. The policy describes existing workplace contact arrangements; a separate public contact remains undecided. Record-disposal criteria and complete historical erasure are documented limits, not newly implemented behavior. See `docs/PRIVACY-VERIFICATION-2026-10-27.md`. GitHub Pages hosting remains optional and is not activated by this release.
