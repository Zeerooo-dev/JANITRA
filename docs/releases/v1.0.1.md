# JANITRA 1.0.1

Android Build 28. October 25, 2026.

- Guided Home setup shows the next step for a manpower agency, client company and workplace, using existing permission checks and creation forms.
- Admin can open unassigned people before creating the first company. The usual dashboard returns after workplace setup, with a Team shortcut.
- Theme-aware aurora backgrounds and glass cards follow the existing appearance colors. High Contrast uses solid surfaces; Motion Off, system reduced motion and app backgrounding stop the background animation.
- Tasks have clearer filter controls, offline-storage notices and empty states.
- Fixes the setup progress layout on narrow phones with large text. Updates light/dark visual regression snapshots and adds motion/lifecycle checks.

This release changes the Android app UI only. It does not deploy Supabase changes, reset records, change roles, or alter PIN verification, task approval or offline submission rules. Existing unassigned-account support remains available.

The APK uses the same production signing key as 1.0.0 Build 27. Compatible installations update in place. JANITRA's update check can offer this newer version on startup; choosing Later leaves the app usable.

No Android phone was connected for this release's physical-device acceptance. Automated checks cover navigation preservation, authentication/authorization regressions, setup actions, appearance and large text. Real-device animation performance and installation acceptance remain to be checked.

The source ZIP contains the source commit used for the signed APK. Signing credentials, local configuration, private backups and one-time local patch installers are excluded. See BUILD-28-2026-10-25.md for the review details.
