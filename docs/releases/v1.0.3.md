# JANITRA 1.0.3 · Build 30

November 27, 2026.

- Fixed Reset Password / initial password setup being replaced by Checking your access during background authorization checks, which cleared typed passwords.
- Brief keyboard/focus interruptions now preserve password input. Personnel setup/recovery also retains its code and passwords through those brief interruptions, while visible secrets are re-masked.
- Actual backgrounding still clears sensitive input. Session expiry, rejected authorization, MFA, sign-out and online password updates retain their security checks.

Version **1.0.3+30** is newer than 1.0.2+29, so the existing in-app GitHub updater can offer this fix. Select Update Now and approve Android's installer, or use About JANITRA → Check for Updates. Existing production-signed installations can update without uninstalling; no account or data reset is required.

Validation: 258 Flutter tests, including 11 new recovery regressions, and 9 native APK safety tests passed locally. Analysis has no errors or warnings; one pre-existing informational style note remains. GitHub Actions builds and verifies the production-signed release APK. APK, matching source ZIP, changes and SHA-256 checksums accompany the release.

No database, RLS, Auth settings, backend deployment or dependency changes. The affected phone still needs to confirm the fix with its actual keyboard. Details: `docs/PASSWORD-RECOVERY-FIX-2026-11-27.md`.
