# JANITRA 1.0.0

Production release: version 1.0.0, Android Build 27.

Maintenance replacement (October 20, 2026): Admin can add unassigned Supervisors and Personnel before creating a manpower company. Accounts receive no workplace permissions until Admin assigns a real company/site. Email invites, username setup codes and later assignment are supported. The replacement keeps version **1.0.0+27** as requested and must be downloaded/installed manually; it will not trigger a newer-version popup. The original `v1.0.0` Git tag remains unchanged; `release-info.json` records the exact maintenance source commit used for the replacement APK and source ZIP.

- Adds About JANITRA to Profile for Admin, Supervisor and Personnel, with the installed version and build number.
- Includes offline-readable third-party licenses for Flutter/Dart packages, Android runtime libraries and all nine bundled fonts.

- Adds an optional update popup with release notes, Update Now and Later.
- Downloads APK updates inside JANITRA with real progress.
- Verifies checksums, package identity, version and signing compatibility before opening Android's installer.
- Keeps workplace navigation, saved work and authentication untouched when Later is selected.
- Adds a manually triggered, production-signed GitHub Actions build. Publishing requires separate approval.

This is the first production-key build. Earlier APKs used a debug signing key. The standard `janitra.apk` is for fresh installations or devices already using the production key. A separate Android 9+ signing-transition APK is included for legacy installations; its signature lineage has been verified locally, but the actual legacy-to-production transition and session retention have not been verified on a physical device. Android 7/8 require a one-time reinstall. Synchronize any drafts before reinstalling, because reinstalling removes local-only data and requires signing in again. Future compatible production-key updates install in place.

The owner has authorized a separate one-time removal of pre-production accounts, agencies and activity after this release, retaining only the existing Admin account. This cleanup is not part of the APK installer and is not a feature that resets future user data.
