# JANITRA 1.0.0

- Adds an optional update popup with release notes, Update Now and Later.
- Downloads APK updates inside JANITRA with real progress.
- Verifies checksums, package identity, version and signing compatibility before opening Android's installer.
- Keeps workplace navigation, saved work and authentication untouched when Later is selected.
- Adds a manually triggered, production-signed GitHub Actions build. Publishing requires separate approval.

This is the first production-key build. Earlier APKs used a debug signing key and cannot be updated directly with this key. Do not uninstall an older installation until pending offline drafts are synchronized. A one-time reinstall requires signing in again and removes local-only data; synchronized server records remain on Supabase. Future updates signed with this production key install in place.
