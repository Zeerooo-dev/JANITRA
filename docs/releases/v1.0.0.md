# JANITRA 1.0.0

- Adds an optional update popup with release notes, Update Now and Later.
- Downloads APK updates inside JANITRA with real progress.
- Verifies checksums, package identity, version and signing compatibility before opening Android's installer.
- Keeps workplace navigation, saved work and authentication untouched when Later is selected.
- Adds a manually triggered, production-signed GitHub Actions build. Publishing requires separate approval.

This is the first production-key build. Earlier APKs used a debug signing key. Android 9+ can use the separately reviewed one-time signing-transition APK to preserve the installed app's data. The standard production APK is for fresh installations or devices already using the production key. Android 7/8 require a one-time reinstall: synchronize offline drafts first, because reinstalling removes local-only data and requires signing in again. Synchronized server records remain on Supabase. Future compatible production-key updates install in place.
